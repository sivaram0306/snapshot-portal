Restore EC2 Volume

Follow the sequence below to replace an existing EC2 volume with a volume created from a snapshot.

1
Select Region Required
2
Select EC2 Instance Waiting
3
Select Volume(s) to Replace Waiting
You can select multiple volumes for this instance. You will map snapshots to them in the next step.
4
Map Snapshots to Selected Volumes Waiting
Choose a snapshot mapping and click **Add to Queue** to build your parallel restoration list.
Restore Sequence
1 Power off EC2 instance
↓
2 Detach existing EBS volume
↓
3 Create new EBS volume from snapshot
↓
4 Attach new volume to EC2 instance
↓
5 Power on EC2 instance
!
Important

This operation will stop the selected EC2 instance, detach the selected volume, create a replacement volume from the selected snapshot, attach the new volume using the same device name, and start the instance again.
